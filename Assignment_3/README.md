# Cursor Landing Page Clone

This project is a static UI clone of the **Cursor** website landing page, built using **HTML and CSS only**.  
The goal of this assignment was to practice real-world UI cloning by recreating the layout, structure, and visual style of an existing product website.

---

## What This Project Includes

- Cursor-inspired dark themed landing page
- Header with navigation and call-to-action buttons
- Hero section with layered background and foreground images
- Trusted-by companies section
- Feature blocks with background + foreground image overlays
- Reviews / testimonials grid
- Use cases section
- Changelog section
- Join us section
- Highlights and final call-to-action
- Footer with:
  - Multiple columns built using `<ul>` and `<li>`
  - Section headings styled using `:first-child`
  - Radio-based theme toggle (System / Light / Dark)
  - Language selector dropdown

---

## Technologies Used

- **HTML5** – structure
- **CSS3** – styling

---

## Responsiveness

- This project is **not responsive**
- It is intended to be viewed on a **standard laptop / desktop screen**
- Best experience at **1280px width or higher**
- Mobile and tablet layouts are not handled
