# Mintlify Landing Page Clone

This project is a front-end clone of the Mintlify marketing website, built using **HTML and CSS only**.  

---

## Sections Recreated

The following sections have been recreated based on visual reference and layout behavior from Mintlify:

1. **Header**
   - Fixed navigation bar
   - Logo, navigation links, and CTA buttons
   - Transparent background with blur effect

2. **Hero Section**
   - Main headline and supporting text
   - Email input CTA
   - Dashboard preview image
   - Bottom fade effect on image using a pseudo-element

3. **Companies Section**
   - Logos of companies using Mintlify
   - Flex-based layout with wrapping support

4. **Features Section**
   - Two feature cards and one wide assistant card
   - Card-based layout with subtle borders
   - Consistent spacing and typography

5. **Enterprise Section**
   - Enterprise-focused messaging
   - Partner and compliance cards
   - Customer story card with overlayed text and stats

6. **Customers Showcase**
   - Three customer cards displayed side by side
   - Navigation buttons (UI only, non-functional)
   - Image + description based card layout

7. **Final CTA Section**
   - Call-to-action encouraging users to get started
   - Gradient background that transitions toward the footer
   - Two action buttons
   - Split layout highlighting pricing and quickstart

8. **Footer**
   - Uses the same background color as the end of the Final CTA
   - Structured with a single content container holding:
     - Brand + social links
     - Navigation link columns
     - System status, copyright
     - Theme switch UI (Light / Dark / System)
   - Borders used to clearly visualize layout structure
